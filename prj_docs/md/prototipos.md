# Protótipos

- Baixa fidelidade: `brain/diagrams/prt_baixa_v1.excalidraw` e `prt_baixa_v2.excalidraw`.
- Alta fidelidade executável: componentes React em `COBECO/apps/web/src`, especialmente `ListsPage.tsx` e `ComparisonPanel.tsx`.

O painel final possui seleção acessível de fornecedores, cobertura percentual, itens ausentes, totais individuais, menor custo consolidado e rótulo textual “Melhor orçamento”. Capturas para o documento ABNT devem ser geradas a partir da aplicação executada em 1440×900, tema claro, usando o seed A–H.
