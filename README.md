# COBECO

O COBECO (Cotação de Bens de Consumo) é uma aplicação web que tem como objetivo geral permitir que usuários realizem cotações online de produtos diversos do mercado varejista, consumindo APIs públicas de comércio eletrônico e reunindo os resultados em uma plataforma única de comparação, facilitando a tomada de decisão de compra por meio da transparência de preços e prazos entre diferentes lojistas. A aplicação contará com uma página inicial (home) leve e informativa, exibindo exemplos de dados retornados, tabelas de produtos e depoimentos de outros usuários sobre a experiência de uso, funcionando como uma vitrine que apresenta a proposta do sistema antes mesmo do cadastro. Após criar uma conta, o usuário será redirecionado à área denominada "plataforma", onde poderá montar listas personalizadas de produtos e solicitar cotações, sendo que essas pesquisas ficarão armazenadas em um banco de dados para consulta futura. O sistema também terá como objetivo comparar automaticamente os resultados obtidos entre os diferentes lojistas consultados, destacando as melhores opções disponíveis com base em dois critérios principais: preço e prazo de entrega. Por fim, busca-se garantir que toda essa experiência seja simples, rápida e confiável para o usuário, mesmo diante da complexidade envolvida na integração com múltiplas fontes externas de dados.
