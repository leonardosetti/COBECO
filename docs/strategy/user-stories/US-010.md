## 1. História

Como **usuário autenticado**,  
eu quero **editar o nome e os itens da minha lista salva**,  
para **manter minhas listas atualizadas conforme minha necessidade**.

---

## 2. Critérios de Aceite — Gherkin

### Cenário 1: Editar nome da lista
```gherkin
Dado que tenho lista ID 123 com nome "Compras Semana"
Quando faço PUT /v1/listas/123 com {"nome": "Compras Quinzenal"}
Então retorna 200 com lista atualizada {id: 123, nome: "Compras Quinzenal", atualizado_em: "..."}
E `atualizado_em` é atualizado para agora
```

### Cenário 2: Editar itens (adicionar, remover, alterar qtd)
```gherkin
Dado que tenho lista ID 123 com itens: Arroz qtd 2, Feijão qtd 1
Quando faço PUT /v1/listas/123/itens com [
  {"produto_id": 1, "quantidade": 3},  -- atualiza Arroz 2→3
  {"produto_id": 2, "quantidade": 0},  -- remove Feijão (qtd 0 = delete)
  {"produto_id": 5, "quantidade": 2}   -- adiciona novo (Óleo)
]
Então retorna 200 com itens atualizados: Arroz 3, Óleo 2
E Feijão removido (soft delete no item ou hard delete do item_lista)
E `atualizado_em` da lista atualizado
```

### Cenário 3: Validação — lista não existe ou não é do usuário
```gherkin
Dado que tento editar lista ID 999 (inexistente ou de outro usuário)
Quando faço PUT /v1/listas/993
Então retorna 404 "Lista não encontrada"
```

### Cenário 4: Validação — quantidade 1-9999
```gherkin
Dado que envio item com quantidade 0 ou 10000
Quando faço PUT /v1/listas/123/itens
Então retorna 400 "Quantidade deve ser entre 1 e 9999" (para qtd > 0)
E qtd 0 remove item
```
