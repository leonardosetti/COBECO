## 1. História

Como **usuário (autenticado ou visitante)**,  
eu quero **selecionar categorias de produtos (11 checkboxes) para filtrar fornecedores disponíveis**,  
para **comparar preços apenas nas categorias que me interessam**.

---

## 2. Critérios de Aceite — Gherkin

### Cenário 1: Exibir 11 categorias com checkboxes
```gherkin
Dado que acesso a página "Comparação" (ou fluxo pré-filtro)
Quando a página carrega
Então exibe 11 checkboxes com nomes das categorias macro (ex: "Alimentos", "Limpeza", "Higiene", ...)
E cada checkbox: label nome + contagem de produtos naquela categoria
E estado inicial: todos desmarcados
```

### Cenário 2: Selecionar categorias → filtra fornecedores em tempo real
```gherkin
Dado que marco checkbox "Alimentos" e "Bebidas"
Quando a seleção muda
Então o sistema faz GET /v1/fornecedores?categorias=1,3 (IDs selecionados)
E atualiza a lista de fornecedores mostrando apenas os que têm produtos nas categorias selecionadas
E cada fornecedor mostra: nome, % disponibilidade (produtos com preço/total nas cat. selecionadas)
```

### Cenário 3: Desmarcar categoria → atualiza fornecedores
```gherkin
Dado que tenho "Alimentos" e "Bebidas" marcados
Quando desmarco "Bebidas"
Então refaz GET /v1/fornecedores?categorias=1
E lista de fornecedores atualiza (pode diminuir)
```

### Cenário 4: Validação — mínimo 1 categoria para prosseguir
```gherkin
Dado que nenhuma categoria selecionada
Quando tento avançar para "Selecionar Fornecedores"
Então botão "Próximo" está desabilitado
E tooltip "Selecione pelo menos uma categoria"
```

## 7. Notas

- **Categorias (Seed):** 1=Alimentos, 2=Bebidas, 3=Limpeza, 4=Higiene, 5=Padaria, 5=Congelados, 7=Laticínios, 8=Frutas/Legumes, 9=Carnes, 10=Mercearia, 11=Outros.
- **% Disponibilidade:** Calculado no backend por fornecedor: `COUNT(DISTINCT fp.produto_id) WHERE fp.produto.categoria_id IN (selecionadas) AND fp.preco IS NOT NULL / COUNT(DISTINCT p.id) WHERE p.categoria_id IN (selecionadas)`.
- **Estado:** Mantido em `sessionStorage` ou context do usuário (chave `cobeco_categorias_selecionadas`).
