## 1. História

Como **usuário autenticado**,  
eu quero **fazer logout do sistema**,  
para **invalidar minha sessão e impedir acesso não autorizado**.

---

## 2. Critérios de Aceite — Gherkin

### Cenário 1: Logout bem-sucedido
```gherkin
Dado que estou autenticado (tenho access_token válido e refresh_token cookie)
Quando faço POST /v1/auth/logout
Então o sistema invalida o refresh_token no backend (blacklist ou deleção)
E remove o cookie refresh_token (max-age=0, SameSite=Strict)
E retorna 200 {"message": "Logout realizado com sucesso"}
E meu access_token em memória no frontend é limpo
E sou redirecionado para a página de login
```

### Cenário 2: Logout sem refresh_token (já expirado/removido)
```gherkin
Dado que meu refresh_token expirou ou foi removido
Quando faço POST /v1/auth/logout
Então o sistema retorna 200 (idempotente)
E limpa o cookie se existir
E redireciona para login
```

## 7. Notas

- **Blacklist Refresh:** Em MVP, usa `set()` em memória no processo backend. Em produção, Redis com TTL.
- **Idempotência:** Logout sempre retorna 200, mesmo se token já inválido.
- **Frontend:** Limpa variável `accessToken` em memória + `window.location.href = '/login'`.
